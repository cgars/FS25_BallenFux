# Changelog

All notable changes to BallenFux are documented in this file.

## [1.0.0.0] - 2026-09-05

### Added

- Initial public release
- Disabled net-wrap consumption for round balers
- Disabled twine consumption for square balers
- Disabled wrapping-film consumption for bale and inline wrappers
- Allowed supported machines to operate with empty consumable stock
- Added multiplayer support
